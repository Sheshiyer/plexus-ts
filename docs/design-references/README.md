# Standalone visual references

[Plexus redesign v1](plexus-redesign-v1.html) is the static Cambium-brand mockup
referenced by the [June 11 design specification](../superpowers/specs/2026-06-11-plexus-ui-redesign-design.md).
Its example data, controls, and layout describe a design concept; they do not
establish current runtime behavior or backend capability.

The original HTML is preserved. Compare it with the later [design collections](../design/README.md)
and [rendered evidence](../evidence/README.md) before reusing a pattern. Current
implementation work belongs in [ISA](../../ISA.md) and [planning](../../.planning/STATE.md),
with navigation through the [documentation map](../DOCUMENTATION_MAP.md).
