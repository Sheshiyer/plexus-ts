# Plexus OTA Hotfix — v0.7.7 → v0.7.8

Status: live root cause captured; minimal adapter correction and focused
regression proof complete; protected integration, publication, and installed
upgrade proof pending.

## Why this patch exists

Signed `v0.7.7` completed the full `v0.7.6` upgrade transition, retained the
authenticated Thoughtseed admin session and workspace, and—after the governed
Hermes catalog producer was deployed—rendered all 15 Temperance lanes as
`READY`.

The first explicit live side-chat turn then failed before a relay request
started. The installed app log captured:

```text
AI_InvalidPromptError: System messages are not allowed in the prompt or
messages fields. Use the instructions option instead.
```

This proves Cloudflare Access, Hermes, OmniRoute, the catalog, and provider
routing are downstream of the failure. The bad state enters when the shared AI
SDK adapter places Clio's system policy inside `messages`.

## Correction

- Ordered system-policy content is extracted into the AI SDK `instructions`
  option.
- System-role entries are removed from the SDK `messages` array.
- Original instruction bytes are preserved; only wholly blank instruction
  entries are ignored. A system role after conversation history is rejected
  instead of being silently reordered.
- User, assistant, tool-call, and tool-result message order and shape remain
  unchanged.
- The correction is shared by every AI-SDK-backed model provider, so the same
  invalid request shape cannot recur on a fallback provider.
- The OmniRoute regression test asserts the exact `instructions` and
  non-system `messages` payload.

No Access assertion, provider credential, signing secret, update credential, or
R2 credential is added or moved by this patch.

## Local correction receipt

- The focused OmniRoute adapter test first failed against the old request shape,
  then passed all ten cases after `instructions` extraction.
- The real installed AI SDK path reached a captured OmniRoute fetch with the
  system instruction plus the exact user, assistant tool-call, tool-result, and
  follow-up user transcript; no `AI_InvalidPromptError` occurred.
- The focused model, OmniRoute, and catalog suites passed 16 tests and

- `npm run verify:all` passed 753 tests, typecheck, placeholder scanning, both
  zero-vulnerability audits, fuse/CSP/evidence policies, deterministic
  production smokes, and the renderer build.
- Lint retained the same seven pre-existing warnings and zero errors.
