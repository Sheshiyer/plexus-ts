## Cloudflare asset-move assessment

The desktop updater only reads the pinned R2 endpoint in `package.json` and
`src/main/updates.ts`. The candidate's git tree for `assets/` is exactly the
same as `origin/main`, and it packages that local tree into the Electron app.
The Identity redesign removes a renderer-public GLB, not a Cloudflare OTA
object. Therefore the moved Cloudflare assets do not affect the local build or
the current installed updater path.

They do affect the next publication if the R2 upload credentials now resolve to
a different bucket or account from the public endpoint above. The publisher
verifies the public URL after upload, but secret names do not expose the bucket
or account values. A new upload must not proceed until the operator proves that
the target serves the pinned feed, or approves a reviewed dual-feed bridge for
the legacy and Labs client cohorts.
